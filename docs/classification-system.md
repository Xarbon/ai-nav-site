# AIqury 分类体系完整报告

## 概述

AIqury 采用**问题驱动的分类体系**，包含 **20 个一级赛道** 和 **133 个二级问题场景**。

- **一级分类**：代表不同的业务领域或职业方向
- **二级分类**：代表该领域内用户实际遇到的具体问题

## 验证规则

### 导入时自动验证

1. **必填字段检查**：工具名称、英文名、官网链接、一句话描述、一级分类、二级分类
2. **分类有效性**：一级分类必须在 20 个预定义 slug 中
3. **二级分类匹配**：二级分类必须属于对应一级分类的问题库
4. **定价模式**：只能是 Free / Freemium / Paid
5. **状态值**：只能是 active / draft / archived
6. **去重逻辑**：如果官网链接已存在，跳过不重复入库

### 错误示例

```
Row 5: Invalid category "marketing_growth" (should be one of 20 valid slugs)
Row 12: Invalid sub_category "seo-tools" for category "ecommerce"
Row 23: Invalid pricing "free" (should be Free/Freemium/Paid)
```
